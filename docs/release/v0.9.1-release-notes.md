# Obsidian AI Workflow Kit v0.9.1

v0.9.1 is a customer-facing language cleanup for the task-first workflow introduced in v0.9.0. It does not change task, handoff, migration, Bases, or installation behavior.

## Download

Choose one Release asset:

| Asset | Use |
|---|---|
| `obsidian-ai-workflow-kit-v0.9.1-en-full.zip` | Ready-to-open English customer vault |
| `obsidian-ai-workflow-kit-v0.9.1-zh-CN-full.zip` | Ready-to-open Chinese customer vault |
| `obsidian-ai-workflow-kit-v0.9.1-en-barebone.zip` | Minimal English foundation for an existing workflow |
| `obsidian-ai-workflow-kit-v0.9.1-zh-CN-barebone.zip` | Minimal Chinese foundation for an existing workflow |

For a new customer, use a `full` archive. Unzip it, open the folder as an Obsidian vault, and read `START.md`.

## What Changed

- Current guidance now describes direct execution, specialist review perspectives, and acceptance criteria in positive task language.
- The generic Agent instruction headings now use `Agent 职责` and `Agent Scope`.
- Templates and onboarding pages no longer expose obsolete routing terminology.
- CI now rejects job-card filenames, obsolete routing metadata, and their return to current customer guidance.
- Upgrade compatibility for old dispatch-card directories remains available through `migrate-v0.9`.

## 中文说明

`v0.9.1` 是一次面向客户的文案收口，不改变任务卡、交接卡、迁移脚本、Bases 或安装行为。

当前规则直接围绕任务目标、专业检查视角和验收标准展开；历史组织术语不再出现在当前开工指南与模板说明中。已有 `v0.8` Vault 仍可使用 `migrate-v0.9` 完成旧任务目录迁移。

中文客户默认下载 `obsidian-ai-workflow-kit-v0.9.1-zh-CN-full.zip`。

## Distribution Boundary

The archives contain generic templates, sanitized examples, scripts, and documentation only. They do not contain private project state, personal paths, raw handoffs, customer data, credentials, or working-vault content.
