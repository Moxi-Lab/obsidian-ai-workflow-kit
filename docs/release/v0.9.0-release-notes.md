# Obsidian AI Workflow Kit v0.9.0

v0.9.0 turns the repository into a downloadable Obsidian vault product while keeping existing-vault upgrades non-destructive.

## Download

Choose one Release asset:

| Asset | Use |
|---|---|
| `obsidian-ai-workflow-kit-v0.9.0-en-full.zip` | Ready-to-open English customer vault |
| `obsidian-ai-workflow-kit-v0.9.0-zh-CN-full.zip` | Ready-to-open Chinese customer vault |
| `obsidian-ai-workflow-kit-v0.9.0-en-barebone.zip` | Minimal English foundation for an existing workflow |
| `obsidian-ai-workflow-kit-v0.9.0-zh-CN-barebone.zip` | Minimal Chinese foundation for an existing workflow |

For a new customer, use a `full` archive. Unzip it, open the folder as an Obsidian vault, and read `START.md`.

## Highlights

- Task-first AI collaboration: execute directly when the current conversation can finish the work.
- No required CEO/CTO/QA-style role cards or role claiming.
- Local task cards only for queued, cross-session, blocked, or explicitly coordinated work.
- Typed status values for projects, sources, tasks, handoffs, reviews, and governance pages.
- `project_entry: true` as the explicit project dashboard membership contract.
- Full-mode Obsidian Bases views for projects, tasks, and sources, with no Dataview or community plugin dependency.
- Read-only checks for relative links, broken and ambiguous Wikilinks, status values, project/task/source fields, Base contracts, and private-looking user paths.
- Four verified Release archives generated from the same installer used by CI.

## Safe Upgrade From v0.8

1. Preview `install.sh --update` using the same language and mode as the current installation.
2. Apply the managed-file update. User-edited and unmanaged files remain untouched.
3. Preview `migrate-v0.9 --dry-run`.
4. Apply the migration only when its task moves and project-entry choices are unambiguous.
5. Run `health-check`.

The migration stops before writing if it would overwrite an existing task file or if a project has multiple current bridge cards. See [`docs/migration.md`](../migration.md) for commands and conflict handling.

`v0.9.0` 将公开仓库升级为可以直接下载、解压并作为 Obsidian Vault 打开的交付产品，同时保留对已有 Vault 的非破坏升级能力。

## Distribution Boundary

The archives contain generic templates, sanitized examples, scripts, and documentation only. They do not contain private project state, personal paths, raw handoffs, customer data, trading information, credentials, or source clips from a working vault.
