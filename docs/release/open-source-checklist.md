# 发布前检查清单

- [x] 仓库没有 `.env`、密钥、Token、Cookie、私钥或本机配置。
- [x] 仓库没有个人资料、真实项目状态、交接历史和运行日志。
- [x] 仓库没有第三方原文、未授权图片和长篇翻译。
- [x] README 说明了公开边界。
- [x] 根目录 `LICENSE` 使用标准 MIT，`docs/legal/content-license.md` 说明文字和模板授权。
- [x] 全仓敏感词扫描无高风险结果。
- [x] GitHub 仓库公开前已完成版本、安装和授权检查。
