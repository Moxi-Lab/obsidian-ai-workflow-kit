# Local Material Intake

当用户说“帮我整理电脑上的资料”时，AI 不应该直接全盘扫描。先让用户给出一个明确范围。

## 开工输入

用户至少提供一种：

- 一个文件夹路径。
- 一批文件路径。
- 一组链接。
- 一段复制来的资料。

## AI 第一步只做清点

先输出：

```text
资料范围：<路径或来源>
资料类型：<项目文档 / 网页资料 / 聊天记录 / 图片附件 / 混合>
建议处理方式：<整理成项目 / 外部资料分析 / 经验资产 / 暂存 Inbox>
不会处理：<本轮不处理的范围>
```

## 分类规则

| 资料类型 | 处理方式 |
|---|---|
| 项目 README、需求、设计、任务记录 | 写入 `10-Projects/` 或项目桥接卡 |
| 文章、网页、论文、帖子 | 写入 `40-ExternalSources/` 的资料分析卡 |
| 反复出现的问题和解决方案 | 写入问题知识卡 / 经验资产卡 |
| 临时想法和未判断资料 | 写入 `01-Inbox/` |
| 模板、流程、检查清单 | 写入 `20-SharedAssets/` 或 `90-Templates/` |

## 整理原则

- 先建索引，再搬内容。
- 先做摘要，再决定是否升舱。
- 先链接已有项目，再新增项目。
- 不把附件、缓存、完整聊天记录直接塞进长期知识。
