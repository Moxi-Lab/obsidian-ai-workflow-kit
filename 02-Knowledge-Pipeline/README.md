# Knowledge Pipeline

这一层告诉 AI：如何把电脑上的资料整理成清晰、可召回、可维护的 Obsidian 知识库。

## 六步流水线

| 步骤 | AI 要做什么 | 产物 |
|---|---|---|
| 1. Intake | 读取用户给出的文件夹、文件或链接清单 | 待处理清单 |
| 2. Classify | 判断资料属于项目、外部资料、经验、模板还是临时信息 | 分类建议 |
| 3. Extract | 提炼摘要、关键结论、来源、适用场景 | 资料分析卡 |
| 4. Connect | 连接到项目、主题、经验或召回地图 | 双向入口 |
| 5. Promote | 把高复用内容升舱为经验资产或问题知识卡 | 长期知识 |
| 6. Maintain | 定期巡检、去重、标注过时、补召回字段 | 健康知识库 |
