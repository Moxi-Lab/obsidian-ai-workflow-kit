# External Sources

这里放外部资料的分析结果，不直接保存第三方原文全文。

## 处理流程

1. 外部资料先进入 `01-Inbox/web-clips/`。
2. 用 `90-Templates/TPL-资料分析卡.md` 判断资料价值。
3. 只保留摘要、来源链接、可复用点和写回去向。
4. 有长期价值的内容，写回项目或共享资产。

## Web Clipper 标签口径

- 原始剪藏只做路由，不直接写成问题知识卡。
- `tags` 只放来源/状态类标签，默认保留 `clippings`。
- `themes` 可先留空，分拣或提炼后再补稳定主题。
- `canonical` 原始剪藏默认 `false`，提炼后的权威问题卡或经验资产卡才设为 `true`。
- `question_text`、`applicable_to` 不写入原始剪藏，只写入 `90-Templates/TPL-问题知识卡-经验资产卡.md`。

## 禁止项

- 不复制第三方文章全文。
- 不保存需要登录才能访问的私密内容。
- 不保存 Cookie、Token、账号信息。
