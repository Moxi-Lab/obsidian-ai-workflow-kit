# Shared Assets

这里放跨项目可复用的规则、SOP、工作流和可选高级模块。

## 子目录

| 路径 | 用途 |
|---|---|
| `02-modules/` | SOP、规范、机制 |
| `03-workflows/` | 可执行工作流 |
| `04-optional-advanced/` | 多 Agent 并行开发等高级场景 |

## 使用规则

- 只放多个项目会重复用到的内容。
- 一次性项目过程不放这里。
- 经验进入这里前，要写清楚适用场景、触发条件和验证方式。

## 可选高级模块

`04-optional-advanced/跨项目多窗口协作写作规范-v2.1.md` 只适合多人或多 Agent 并行开发。单人使用 Obsidian AI Workflow Kit 时可以跳过。
