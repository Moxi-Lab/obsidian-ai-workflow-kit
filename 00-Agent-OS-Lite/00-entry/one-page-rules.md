# 一页纸规则

## 核心原则

- 少做假设。
- 少做无关改动。
- 少做过度设计。
- 先明确完成标准，再完成任务并验证结果。

## 开工规则

1. 先读 `START-HERE.md`。
2. 判断任务类型。
3. 只打开和任务有关的项目桥接卡、模板或共享资产。
4. 不知道写到哪里时，先写到对应 Inbox，并留下下一步。

## 写回规则

| 情况 | 写回位置 |
|---|---|
| 项目状态变化 | 项目桥接卡 |
| 任务短期交接 | `01-Inbox/agent-handoffs/` |
| 可复用经验 | `20-SharedAssets/02-modules/` |
| 外部资料分析 | `40-ExternalSources/` |
| 模板变化 | `90-Templates/` |

## 禁止项

- 不保存密钥、Token、Cookie、验证码、私钥。
- 不把完整聊天记录写入知识库。
- 不在没有要求时批量重构目录。
- 不把 Inbox 当长期知识库。
- 不直接复制第三方原文全文。
