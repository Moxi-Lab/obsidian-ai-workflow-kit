# Web Clips Inbox

这里放临时网页剪藏和外部资料入口。

处理规则：

- 不保留第三方原文全文。
- 用 `90-Templates/TPL-资料分析卡.md` 判断价值。
- 有用结论写回项目或共享资产。
- 原始剪藏默认 `type: web-clip`、`status: inbox`、`tags: [clippings]`、`canonical: false`。
- 不在原始剪藏中填写 `question_text`、`applicable_to`；这些字段只用于提炼后的问题知识卡或经验资产卡。
