# Inbox

Inbox 是临时流转区，不是长期知识库。

三个子目录只负责分流，不负责沉淀。当前对话可以完成的任务直接执行，不需要先建卡：

## 子目录

| 路径 | 用途 |
|---|---|
| `agent-handoffs/` | 当前会话结束、任务中断或需要下一次 AI 接手时使用 |
| `tasks/` | 需要排队、跨会话继续或等待外部条件的本地任务卡 |
| `web-clips/` | 网页剪藏、外部资料和本机资料的临时入口 |

## 处理原则

- 能进入项目的，写回 `10-Projects/`。
- 能复用的，上浮到 `20-SharedAssets/`。
- 只用于参考的，整理到 `40-ExternalSources/`。
- 网页剪藏或本机资料先转成 `40-ExternalSources/` 的资料分析卡，再判断是否升舱。
- 已完成的，归档或删除临时副本。
- 需要专业视角时，直接写进任务目标或验收标准。
