# Obsidian Bases 动态视图

这些视图只随 `full` 模式安装，使用 Obsidian 自带的 Bases 核心插件，不依赖 Dataview 或社区插件。

- `项目总览.base`：显示设置了 `project_entry: true` 的项目权威入口。
- `任务总览.base`：显示排队中、进行中、阻塞、完成和归档的本地任务。
- `资料总览.base`：显示已收录的外部资料分析卡和文件夹清单。

Markdown 页面始终是事实来源。Base 只是基于 Frontmatter 的动态视图，因此 `health-check` 会守护视图使用的每个字段。
